# CLA signatures

This branch holds only the Contributor Licence Agreement signatures recorded by the CLA
check (LI-05, `.github/workflows/cla.yml`). The bot writes them to `signatures/cla.json`.

Do not protect or delete this branch: the bot must be able to push to it, and deleting it
loses every recorded signature.
